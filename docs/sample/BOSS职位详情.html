    职位描kanzhun述

    【岗位描kanzhun述】
    负责多模态大模型BOSS直聘及 AI 全栈产品在企业客户侧的端到端交付，对交付结果负责。该岗位不是纯项目协调角色，需要具备对多模态大模型技术及落地链路的基本理解，并具备部分 FDE（前线技术交付）能⼒，能够在客户现场完成需求澄清、⽅案拆解、技术问题初步定位，并牵引 Infra、算法及应⽤研发团队协同交付。
    【岗位职责】
    1. 负责 AI 全栈产品（IaaS / PaaS / MaaS / Agent / Studio）及多模态大模型能力在 B 端客户侧的端到端交付，对项⽬进度、质量、验收及回款结果负责。
    2. 深入理解客户业务场景与需求，能够结合文本、图像、视频、语音等多模态能力，与客户及内部技术团队共同制定可落地的交付方案、实施路径和项目里程碑。
    3. 承担部分 FDE 职责：参与客户需求调研、技术方案沟通、PoC 验证、接口联调、上线支持及现场问题初步排查；能够将客户业务问题准确拆解为内部技术团队可执行的交付任务。
    4. 统筹 Infra、模型算法、平台及应用研发资源，推动模型服务、API 接入、Agent、知识库、推理部署及行业应用等相关能力的集成交付。
    5. 主导项目全流程管理，包括范围、计划、进度、质量、风险、变更、验收及回款管理，及时识别项目风险并推动跨团队问题闭环。
    6. 根据项目需要驻场或出差，沉淀多模态大模型项目的行业解决方案、交付方法论及项目资产。
    【岗位要求】
    1. 本科及以上学历，3 年以上 B 端项目交付、技术项目管理、解决方案实施或客户成功相关经验，独立负责过中大型企业客户项目。
    2. 具备完整的企业客户项目交付经验，能够独立推进需求调研、方案拆解、PoC、联调、上线、验收及回款等关键环节。
    3. 对多模态大模型具备一定技术理解，了解文本、图像、视频、语音等多模态 AI 的典型业务场景、能力边界和基础落地方式；能够与算法、平台、Infra 及应用研发团队进行有效沟通。
    4. 了解大模型应用的基本交付链路，包括 MaaS / API 调用、模型服务、Agent、RAG / 知识库、推理部署、私有化部署或云上部署等；不要求亲自开发，但能够理解技术方案、识别交付风险并推动解决。
    5. 具备部分 FDE 或一线技术交付能力：能够面向客户完成技术需求澄清、基础方案沟通、接口或系统联调协调、现场问题初步定位及闭环推动。
    6. 熟悉项目管理全流程，熟练使用 Jira、禅道、飞书项目等协作管理工具。
    7. 沟通表达、客户管理及情绪管理能力强，责任心强，抗压能力好，能够适应灵活驻场或出差。
    【加分项】
    1. 有头部 AI 公司、云计算公司、咨询公司、行业 ISV 或企业软件公司交付背景。
    2. 有多模态大模型、视觉 AI、语音 AI、智能客服、知识库 / RAG、Agent、模型 API 或私有化部署项目的实际交付经验。
    3. 有金融、政企、制造、能源、运营商等重点行业客户经验。
    4. 有客户现场 PoC、接口联调、模型能力验证、上线验收或复杂技术问题协同解决经验。
    5. 持有 PMP、PRINCE2 等项目管理认证。
    【我们能为你提供】
    1、直接参与前沿 AI 场景中的数据基础设施建设，接触海量音视频、文本、图片等多模态数据和大规模算力系统。
    2、与高密度工程团队协作，和来自复旦、创智学院等背景的研究员与工程师一起解决真实复杂问题。
    3、在快速发展的早期团队中承担核心职责，对数据平台和训练数据体系拥有实际影响力。
    4、有竞争力的薪酬和福利，对于突出贡献者授予公司期权。
