# 清空确认弹窗字号调整设计

## 目标

提高“清空已收集职位”确认弹窗的可读性，同时保持 Side Panel 的紧凑布局和既有视觉层级。

## 范围

- 清空确认弹窗标题字号调整为 `18px`。
- 清空确认弹窗说明文字字号调整为 `14px`。
- 清空确认弹窗“取消”和“确认清空”按钮字号调整为 `14px`。
- 保持弹窗宽度、内边距、颜色、遮罩、按钮尺寸和交互不变。
- 备注编辑弹窗、岗位列表、提示气泡及 Side Panel 其他文字保持现状。

## 实现约束

使用清空弹窗已有的 `data-dialog="clear"` 属性限定 CSS 选择器，避免影响备注编辑弹窗。不得新增 UI 元素或修改业务逻辑。

## 验收标准

1. 清空确认弹窗标题计算字号为 `18px`。
2. 确认说明文字及两个按钮计算字号为 `14px`。
3. 备注编辑弹窗标题、标签、输入框和按钮字号不变。
4. 清空确认、取消、键盘焦点与其他既有功能测试全部通过。
