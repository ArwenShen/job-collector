# 底部操作按钮字号调整设计

## 目标

提高 Side Panel 底部“导出 CSV”和“清空”按钮的可读性，并与清空确认弹窗按钮形成一致的文字层级。

## 范围

- “导出 CSV”按钮字号调整为 `14px`。
- “清空”按钮字号调整为 `14px`。
- 保持按钮高度、宽度、边框、颜色、间距、启用/禁用状态和交互不变。
- 岗位列表、收集按钮、备注弹窗、清空确认弹窗及其他文字保持现状。

## 实现约束

使用已有 `.panel-footer button` 选择器设置字号，不新增 UI 元素，不修改业务逻辑。

## 验收标准

1. 两个底部按钮的计算字号均为 `14px`。
2. 底部按钮仍各占一半可用宽度，保持 `36px` 最小高度。
3. 导出、清空确认和禁用状态行为不变。
4. 现有类型检查、测试与生产构建全部通过。
