# 主要操作按钮字号调整设计

## 目标

提高 Side Panel 底部操作按钮和备注弹窗操作按钮的可读性，并与清空确认弹窗按钮形成一致的文字层级。

## 范围

- “导出 CSV”按钮字号调整为 `14px`。
- “清空”按钮字号调整为 `14px`。
- 备注弹窗“取消”和“保存”按钮字号调整为 `14px`。
- 保持按钮高度、宽度、边框、颜色、间距、启用/禁用状态和交互不变。
- 清空确认弹窗按钮继续保持 `14px`。
- 岗位列表、收集按钮、备注标题、备注标签、备注输入框、清空确认弹窗标题与说明及其他文字保持现状。

## 实现约束

使用已有 `.panel-footer button` 设置底部按钮字号，并使用备注弹窗已有的 `data-dialog="note"` 限定其操作按钮字号。不得通过共享 `.dialog-actions button` 影响其他弹窗，不新增 UI 元素，不修改业务逻辑。

## 验收标准

1. 两个底部按钮的计算字号均为 `14px`。
2. 备注弹窗“取消”和“保存”按钮的计算字号均为 `14px`。
3. 底部按钮仍各占一半可用宽度，保持 `36px` 最小高度；备注弹窗按钮尺寸不变。
4. 备注弹窗标题、标签和输入框字号不变，清空确认弹窗既有字号不变。
5. 导出、备注保存/取消、清空确认和禁用状态行为不变。
6. 现有类型检查、测试与生产构建全部通过。
