# 按平台可选网站权限设计 Spec

## 1. 文档状态

- 状态：设计已确认并进入实施
- 日期：2026-09-05
- 变更类型：改善 Side Panel 在新标签页中的职位收集授权体验
- 前置 Spec：`docs/superpowers/specs/2026-09-03-job-collector-side-panel-design.md`

本 Spec 只覆盖网站访问授权。前置 Spec 中的职位提取、字段校验、本地存储、列表、备注、删除、清空、CSV 和隐私边界继续有效。前置 Spec 中“不新增 host permissions”和“新标签页必须再次点击扩展图标”的条款，由本 Spec 的按平台可选网站权限方案替代。

## 2. 目标

用户保持岗位收集器 Side Panel 打开并切换到招聘网站的新职位标签页后，可以直接点击“收集当前职位”。如果该平台尚未获得网站访问权限，插件通过 Chrome 官方权限入口申请当前平台权限；用户允许后自动继续收集当前岗位，不再要求关闭并重新打开 Side Panel。

成功意味着：

- BOSS 收藏列表的同标签页流程保持原样，不出现多余授权。
- BOSS、猎聘、智联招聘和前程无忧按平台分别授权，而不是一次授权四个平台。
- 每个平台授权一次后，该平台后续新标签页可以直接收集。
- 授权不会导致自动扫描标签页、自动收集或扩大到其他网站。
- 授权期间切换、关闭或导航标签页时，不会误收集其他页面。

## 3. 方案选择

采用“四个平台均声明为可选网站权限，实际缺少权限时才请求当前平台”的方案。

不采用只配置猎聘、智联招聘和前程无忧的方案，因为 BOSS 也可能从搜索结果、聊天链接或其他入口打开到新标签页。BOSS 当前同标签页路径能够继续依赖 `activeTab`，因此正常使用时不会出现授权提示；只有 BOSS 实际缺少访问权限时才申请。

不采用固定 `host_permissions`，避免在安装或升级时直接要求四个平台的长期访问权限。不新增 `tabs` 权限，因为读取全部标签页 URL 会扩大隐私权限范围。

## 4. Manifest 权限

保留现有必需权限：

```json
{
  "permissions": ["activeTab", "scripting", "storage", "sidePanel"]
}
```

新增精确限定的可选网站权限：

```json
{
  "optional_host_permissions": [
    "https://*.zhipin.com/*",
    "https://*.liepin.com/*",
    "https://*.zhaopin.com/*",
    "https://*.51job.com/*"
  ]
}
```

约束：

- 不使用 `<all_urls>`、`http://*/*` 或 `https://*/*`。
- 不新增 `tabs`、浏览历史、Cookie、下载或网络请求相关权限。
- `activeTab` 继续保留，负责用户点击扩展图标时的临时授权和无需持久权限的原有路径。
- 可选网站权限必须由用户在运行时按平台授予；未授予的平台不可注入脚本。

## 5. 授权架构

### 5.1 Active-tab extraction

每次点击“收集当前职位”仍重新查询当前窗口的激活标签页，不缓存旧职位内容。

提取器首先按现有方式向当前标签页注入 `content.js`：

- 注入成功：继续现有平台识别、详情页判断、必需字段校验与保存流程。
- 注入因缺少网站访问权限失败：返回结构化的“需要网站授权”结果，并携带当次标签页 ID。
- 其他注入错误：进入现有读取失败处理，不触发网站授权。

业务控制器不通过解析错误文案决定授权平台，也不读取全部标签页 URL。

### 5.2 Host-access coordinator

新增独立的网站授权协调单元，职责仅包括：

- 接收用户选中的平台与待授权标签页 ID。
- 把平台映射到 Manifest 已声明的精确 origin，并在平台按钮的用户手势中立即调用 `chrome.permissions.request({ origins })`。
- 授权完成后重新查询当前激活标签页；只有仍为原标签页时才允许自动重试。
- Side Panel 销毁后忽略未完成的授权结果。

每次只申请用户点选的一个平台，不会连带申请另外三个平台。若选错平台，授权后的提取仍会失败，侧边栏保留平台选择并明确提示重新选择。

### 5.3 Pending collection

控制器最多保存一个待授权收集标识，只包含标签页 ID 和内部请求序号，不缓存岗位数据或网页 HTML。

用户允许权限后：

1. 用户点击临时出现的平台按钮。
2. 立即申请该平台的可选网站权限。
3. 重新查询当前窗口的激活标签页。
4. 只有激活标签页仍是原标签页时，才重新执行提取。
5. 自动重试最多一次；重试仍因权限失败时保留选择器并提示平台不匹配，不再次循环申请。
5. 保存、去重和列表刷新继续使用现有流程。

新的收集点击会替换旧的待授权请求。重复点击在忙碌期间无效；现有 `source_site + source_job_id` 去重仍作为最后一道保护。

## 6. 用户流程与文案

### 6.1 已有访问权限

```text
点击“收集当前职位”
→ 读取当前标签页
→ 提取并保存
→ 显示“已收集当前职位”或现有重复更新提示
```

BOSS 收藏列表在同标签页内切换职位时走此路径，不显示权限提示。

### 6.2 首次缺少平台权限

```text
点击“收集当前职位”
→ Chrome 拒绝脚本注入
→ 侧边栏临时显示四个平台按钮
→ 显示“请选择当前招聘平台并允许网站访问；每个平台只需授权一次”
→ 用户点击当前页面所属平台并确认 Chrome 权限请求
→ 插件确认标签页仍有效
→ 自动重试并完成收集
```

平台按钮只在缺少权限时出现，授权流程结束后消失；不新增常驻权限设置入口。

### 6.3 授权未完成或上下文变化

- 用户拒绝或关闭 Chrome 权限请求：不保存数据，保留平台按钮并显示“未允许访问该平台，请授权后重试”。
- 用户点击错误平台：不保存数据，保留平台按钮并显示“所选平台与当前页面不一致，请重新选择”。
- 权限请求完成时，如果用户已经切换到其他标签页：不收集新标签页，显示“网站访问已授权，请回到原职位页重新收集”。
- 原标签页关闭或重新加载：取消自动重试；用户在目标职位页重新点击收集。
- 权限授权后被用户撤销：下次缺少权限时重新走按平台授权流程。
- 当前网站不匹配四个平台：Chrome 不授予网站权限，并继续使用“不支持平台”的错误处理。

## 7. Chrome 版本兼容

通过功能检测判断 `chrome.permissions.request` 是否存在。API 不可用或调用异常时不报运行时错误，不修改权限，并显示“无法发起网站授权，请重试”。不使用宽泛网站权限或 `tabs` 权限。

## 8. 隐私与产品边界

获得某个平台网站权限后，扩展在技术上可以向该平台页面注入本地脚本；产品行为仍严格限制为用户点击“收集当前职位”后才执行提取。

本次变更不得：

- 遍历或读取未激活标签页。
- 自动点击、扫描或批量处理职位列表。
- 在页面打开、切换或授权完成之外自动收集多个岗位。
- 发送岗位、账号、Cookie 或页面内容到网络。
- 增加爬虫、自动投递、AI 托管、遥测或云同步。

所有岗位数据继续只保存在 `chrome.storage.local`，CSV 继续由本地浏览器生成。

## 9. 自动化测试

### 9.1 Manifest contract

- 必需权限保持 `activeTab`、`scripting`、`storage`、`sidePanel`。
- `optional_host_permissions` 与四个平台 HTTPS 域名模式完全一致。
- 不包含宽泛 host pattern、`tabs` 或其他未批准权限。

### 9.2 Extraction and controller

- 正常注入成功时不调用网站授权协调器。
- 只有缺少 host access 的注入失败才产生结构化授权请求。
- 非权限类异常继续显示读取失败，不申请网站权限。
- 缺少权限时只显示临时平台按钮，不自动发起请求。
- 每个平台按钮只请求对应的精确 origin。
- 相同标签页授权成功后只自动重试一次并保存一次。
- 活跃标签页不同或原标签页关闭时不自动提取。
- 拒绝、API 不可用和平台选择错误都有明确反馈。
- 控制器销毁后未完成的授权结果不触发提取或渲染。

### 9.3 Regression

- 现有四平台提取器、去重、存储、列表、备注、删除、撤销、清空和 CSV 测试全部通过。
- 类型检查与两套 Vite 生产构建通过。
- 构建产物不包含远程脚本、远程字体或未批准权限。

## 10. 真实 Chrome 验收

1. BOSS 收藏列表在同一标签页切换并收集多个职位，全程不出现授权提示。
2. 猎聘新标签页首次收集时出现猎聘网站访问请求；允许后自动收集该职位。
3. 智联招聘和前程无忧分别完成各自的一次性授权，不连带授予其他平台。
4. 已授权平台后续新职位标签页可以直接收集，无需关闭或重新打开 Side Panel。
5. BOSS 新标签页只有在缺少访问权限时才请求 BOSS 权限。
6. 授权期间切换、关闭或刷新标签页，不会收集错误职位。
7. 用户撤销某个平台的网站访问权限后，该平台下次收集重新请求授权。
8. 不支持的网站不会获得权限，也不会保存记录。
9. 如果运行环境无法发起可选权限请求，侧边栏显示明确错误且不丢失已收集数据。
10. CSV、去重、备注、删除、撤销和清空行为保持不变。
