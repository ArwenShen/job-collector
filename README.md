# 岗位收集器

## 功能

在 BOSS直聘、猎聘、智联招聘和前程无忧的职位详情页中，通过 Chrome 原生右侧 Side Panel 主动收集完整岗位信息并导出 CSV。

## 安装

1. 运行 `npm install` 和 `npm run build`。
2. 打开 `chrome://extensions` 并启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择项目的 `dist/` 目录。Chrome 应始终加载构建后的 `dist/`，而不是 `src/`。

## 使用

1. 打开 BOSS直聘、猎聘、智联招聘或前程无忧的职位详情页。
2. 在当前标签页点击 Chrome 工具栏中的“岗位收集器”扩展图标，打开或聚焦浏览器右侧面板。
3. 点击“收集当前职位”。切换到新的标签页或平台后，需要在该标签页再次点击扩展图标，以授予扩展访问当前页面的 `activeTab` 权限，然后再收集。
4. 将鼠标悬停在字段上，或用键盘将焦点移到字段上，可查看完整内容；也可以编辑备注或单条删除职位。
5. 点击“导出 CSV”下载全部已收集记录。

## 数据管理

- 单条删除后可在 5 秒内撤销。
- “清空”会要求确认；确认后删除全部本地记录，且不可撤销。
- 重复收集同一职位会更新职位数据，但保留原备注和列表位置。
- CSV 包含完整 JD 和备注；导出不会清空任何记录。

## CSV 内容

导出文件包含平台、职位 ID、原页地址、职位名称、公司、薪资、地点、经验、学历、完整 JD、公司介绍、备注、缺失字段和收集时间等字段。文件使用 UTF-8 BOM、CRLF 换行并对所有字段加引号，便于 Excel 和后续岗位分析工具读取。

## 隐私

数据仅在浏览器本地处理和保存。扩展不发送网络请求，不读取未被用户主动打开的岗位。扩展仅申请 `activeTab`、`scripting`、`storage` 和 `sidePanel` 权限，不申请持久化的站点（host）权限。

## 限制

不自动遍历职位列表，不连续收集，不自动投递，不做 AI 分析，不提供云同步。
